# Agent Manifest & Specializations

## 1. CoreLogicAgent (The Algorithm Engineer)
- Role: Implements the graph definitions, state management loops, and mathematical latency prediction functions.
- Constraint: Write pure, deterministic TypeScript code. Do not author markup or mix UI style configurations into calculation code blocks.

## 2. InterfaceArchitectAgent (The Frontend Stylist)
- Role: Consumes calculated states from the logic engine and maps them onto semantic Tailwind layouts.
- Constraint: Adhere strictly to the color token guidelines found in `design.md`. Keep components responsive and clean without loading secondary structural libraries.

## 3. QAValidatorAgent (The Edge-Case Inspector)
- Role: Reviews built modules to guarantee state mutations run smoothly without breaking components.
- Constraint: Force verification of critical edge cases (e.g., verifying how the system displays calculations when a node has zero historical logs or when the form hits the final null node).
